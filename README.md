# Open Screen Recorder (by Graphicarray)

Offline Windows screen capture & crash-safe video recorder styled with Graphicarray brand rules.

## Build EXE on GitHub
1. Upload the contents of this zip to a GitHub repository.
2. Go to the **Actions** tab and run **Build Open Screen Recorder EXE** (or push to `main`).
3. Download `OpenScreenRecorder.exe` from the workflow artifacts.
