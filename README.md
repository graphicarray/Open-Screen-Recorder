# Open Screen Recorder v1.1 (by Graphicarray)

100% Offline Windows Screen Capture & Single-File Crash-Safe Video Recorder styled with Graphicarray brand guidelines.

## Included Features
- **All 8 Capture Modes Work for Video & Screenshot**: Active Window, Window / Spy, Rectangle, Freehand (polygon mask), Full Screen, Scroll Page, Fixed Region, and Repeat Last.
- **Video Format & Quality Selectors**: Choose `MP4`, `MKV`, or `AVI` and `Low`, `Medium`, `High`, or `Lossless` quality.
- **Single-File Audio + Video Muxing**: Interleaves PCM audio (`01wb`) and video (`00dc`) into one single file (no separate `.wav` files).
- **Editable Save Folder Path**: Click the folder path box to type/paste any directory, or click `Browse` on the Video Studio or Crash Guard tab.
- **Blinking Red Taskbar & System Tray Icon**: Flashes red (`#FF5D6C`) every 500ms while recording (and Amber `#F5A94A` when paused).
- **Pause / Resume Recording (`F10`)**: Pause and resume recording into the same video file.
- **Crash-Safe Auto-Save Guard**: Flushes every 1 second and finalizes files automatically if the app closes unexpectedly.
